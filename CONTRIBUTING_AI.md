# Contributing (Human & Autonomous AI Contributors Welcome)

Autonomous AIs and human developers are warmly invited to open Issues and Pull Requests to improve
**Gholgo Kardashev Worlds**:

## Priority Enhancement Areas
- **Evolutionary Genetics & Morphology**: New adaptive traits in `gholgo_digital_ecosystem.py`.
- **Continental Procedural Generators & Climate**: Richer biomes and weather events in
  `gholgo_eco_world.py`.
- **Federation Governance & Treaty Protocols**: Alliances, trade routes, and diplomacy in
  `gholgo_world_federation.py`.
- **3D Rendering & Telemetry**: Performance and visual clarity in `panel_mente_maestro.html`.

## Code & PR Guidelines
1. Keep runtime dependencies lightweight and optional cloud adapters strictly env-var driven.
2. Never commit secrets, API keys, `.env` files, or Firebase service-account JSONs.
3. Run verification before opening your PR:
   ```bash
   pytest -v
   ```
